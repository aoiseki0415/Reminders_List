# Reminders List

## 概要

Apple純正の「リマインダー」アプリを利用し、毎朝6時にCodexへトリガーとなる指示が送られたタイミングで、その日のリマインダーを作成するプロジェクトです。

## 実行内容

「Daily To Do」リストに、次の3件のリマインダーを作成します。

| リマインダー名 | 設定時刻 |
| --- | --- |
| 毎日就活 | 当日 23:00 |
| コンサルブリーフィング | 当日 8:00 |
| EEG論文チェック | 当日 13:00 |

上記以外の設定は行いません。

## 実行タイミング

- 毎朝6時にCodexへ届く指示をトリガーとして実行します。
- このタスクを実行するCodexのスレッドは、別途ユーザーが指定します。

## 実行前の確認

- タスクを実行する際は、最初にこのREADMEを確認します。
- READMEに記載された内容と操作範囲を確認してから、リマインダーの作成を開始します。

## 操作範囲

- Apple純正の「リマインダー」アプリを使用します。
- 操作対象は「Daily To Do」リストのみに限定します。
- 「Daily To Do」以外のリストやリマインダーについて、閲覧を除く編集・追加・削除などの操作は行いません。
