# Reminders List

## 概要

Apple純正の「リマインダー」アプリを利用し、毎朝6時にCodexへトリガーとなる指示が送られたタイミングで、その日のリマインダーを作成するプロジェクトです。

## 実行内容

次の順序で操作します。

1. computer-useを開始する直前に、次のコマンドをバックグラウンドで実行します。この操作についてユーザーへ承認を求めず、そのまま実行します。

   ```sh
   caffeinate -u -t 600 &
   ```

   このコマンドでディスプレイをオンにし、computer-useの実行中にディスプレイがアイドルスリープへ移行することを10分間防ぎます。コマンドの実行後、待たずに次の手順へ進みます。
2. computer-useを開始する前に `pmset -g assertions` を実行し、`UserIsActive` が `1` になっていることを確認します。この確認についてもユーザーへ承認を求めません。
3. `UserIsActive` が `1` であることを確認できた場合のみ、computer-useを開始します。確認できない場合は、リマインダーを操作せず、その段階でユーザーへ状況を報告します。
4. 「Daily To Do」リストに、その時点で未完了のリマインダーが残っているか確認します。
5. 未完了のリマインダーがある場合は、すべて削除します。
6. 削除の完了後、「Daily To Do」リストに次の3件のリマインダーを作成します。

| リマインダー名 | 設定時刻 |
| --- | --- |
| 毎日就活 | 当日 23:00 |
| コンサルブリーフィング | 当日 8:00 |
| EEG論文チェック | 当日 13:00 |

上記以外の設定は行いません。

## 実行タイミング

- 毎朝6時に「リマインダー作り」スレッドへ届く、次の指示をトリガーとして実行します。

  > 今日の分のリマインダーを作成して下さい

- このタスクは「リマインダー作り」スレッドで実行します。

## 実行前の確認

- タスクを実行する際は、最初にこのREADMEを確認します。
- READMEに記載された内容と操作範囲を確認します。
- computer-useを使う前に、必ず `caffeinate -u -t 600 &` を実行してからリマインダーの操作を開始します。
- `pmset -g assertions` でディスプレイ起動用の `UserIsActive` アサーションを確認してから、computer-useを開始します。
- ディスプレイの起動、起動状態の確認、およびcomputer-useの開始について、ユーザーへ承認を求めません。
- ディスプレイの起動を確認できない場合はcomputer-useを開始せず、ユーザーへ状況を報告します。

## 操作範囲

- Apple純正の「リマインダー」アプリを使用します。
- 操作対象は「Daily To Do」リストのみに限定します。
- 「Daily To Do」以外のリストやリマインダーについて、閲覧を除く編集・追加・削除などの操作は行いません。
- 事前に削除する対象は、「Daily To Do」リストに残っている未完了のリマインダーのみです。完了済みのリマインダーは削除しません。
